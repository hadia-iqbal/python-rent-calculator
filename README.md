# 🏠 Python Rent Calculator Project

This is a simple **Python project** that calculates the total rent of a flat/hostel by including different expenses such as food, electricity, gas, and internet.  
It also divides the total cost among the number of people living together.

---

## ✨ Features
- Input hostel/flat rent
- Add food expenses
- Calculate electricity bill (units × per unit charge)
- Include gas and internet bills
- Calculate **total monthly payment**
- Split expenses among flat/hostel mates
- Rounded result for **per person rent**

---

## 🖥️ How to Run
1. Make sure you have **Python 3.x** installed.
2. Save the code in a file named `rent_calculator.py`.
3. Open terminal or command prompt in the project folder.
4. Run the program
